# 网易云音乐版权上传助手

独立于 `qq-music-uploader` 的 Chrome Manifest V3 扩展，目标页面：

`https://music.163.com/st/licensor-service/workmanagement/upload/0?uploadType=upload_album_new`

## 使用

1. Chrome 打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，指向本目录。
2. 登录网易云音乐版权服务平台并打开作品上传页面。
3. 扩展弹窗中选择音频；歌词可按相同文件名匹配，例如 `song.mp3` 对 `song.txt`。
4. 填写演唱者、词作者、曲作者等元数据。扩展按输入框直接写入用户指定的文字，不自动点击艺人建议；平台若要求绑定艺人实体，需由用户在页面中自行确认。
5. 先在网页上传音频，确认“歌曲”列表出现该歌曲行；点击“开始处理”后，扩展进入该行的“编辑”抽屉并填写信息。默认只填表不提交；勾选“自动点击提交”后，只有观察到平台上传完成和可点击的“提交”按钮才会点击。

## 边界

- 不读取 Cookie、Token，不调用网易云私有接口，不绕过验证码、版权校验或平台限制。
- 扩展只使用用户显式选择的本地文件。
- 无法找到字段、找不到匹配艺人、音频上传未完成或提交后没有页面确认时会停止并显示错误，不会假报成功。
- 现阶段网易云网页的音频控件可能不是可通过 DOM 确认的文件框。扩展不会猜测并向任意文件框上传音频；遇到该情况请先手动在网页上传音频。页面有多首歌曲行时，扩展也不会猜测应编辑哪一行。
- 截图中的账号、公司、作者、价格、原创/翻唱和预售选项没有硬编码；这些属于每首歌曲的用户/版权信息。

## 当前版本验证

这是 DOM 适配型 MVP。不同账号的表单字段、下拉选项和页面文案可能不同；未连接真实账号时只能做静态检查和模拟 DOM 回归，不能宣称已在网易云平台端到端上传成功。
